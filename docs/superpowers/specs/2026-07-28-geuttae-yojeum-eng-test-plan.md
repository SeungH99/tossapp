## Key Interactions to Verify

- 핵심 세 문제를 광고 없이 완료하고 결과를 확인한다.
- 답안을 빠르게 두 번 눌러도 한 번만 채점한다.
- 첫 보너스는 광고 없이 한 번만 열리고 복구 후 다시 무료 처리되지 않는다.
- 3일·7일 연속 참여 무료권은 같은 연속 참여 구간에서 한 번씩만 지급되고, 사용 시 한 장만 차감된다.
- 무료 해제 수단이 없을 때만 광고를 제안하며, 성공 시 보너스가 한 번만 열리고 취소·실패 시 열리지 않는다.
- 선택한 주제의 미풀이 문제를 우선하고 부족한 수만 다른 미풀이 주제로 채운다.
- 출시·샌드박스 환경에서 올바른 공유 링크를 생성한다.
- 과거 challenge가 오늘 기록·연속 참여·알림 자격·KPI를 바꾸지 않는다.
- 서로 다른 날짜에 두 번 완료한 사용자에게만 알림 카드를 보여준다.
- 새로고침·백그라운드 복귀 후 진행과 outbox를 복구한다.

## Edge Cases

- 첫 무료 해제와 무료권 차감 중 더블클릭·새로고침·저장 재시도
- 같은 `streakStartDate + milestone` 지급 이벤트 중복 처리
- 광고 중복 콜백, 취소, 타임아웃
- deployment ID 누락, 잘못된 challenge 날짜, 클립보드 실패
- 보너스 미풀이 문제가 세 개 미만
- 알림 SDK 미지원·권한 거부·해지 실패

- 360px 화면, 200% 글자 확대, 키보드 전용, 감소된 모션

## Critical Paths

1. 신규 사용자: 홈 → 핵심 3문제 → 결과
2. 재방문 사용자: 중간 진행 복구 → 완료 → 연속 참여 갱신
3. 보너스: 결과 → 주제 선택 → 첫 무료 또는 무료권 → 주제 우선 보너스 3문제
4. 수익화: 무료권 없음 → 보상 광고 완료 → 주제 우선 보너스 3문제
5. 바이럴: 결과 → 같은 날짜 공유 → 수신자의 동일 핵심 문제
6. 리텐션: 서로 다른 날짜 2회 완료 → 알림 동의 → 설정에서 해지
7. 출시: CI 검증 → `dist` 산출물 → 콘솔 업로드 → iOS·Android QR 테스트
