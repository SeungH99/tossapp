# 그때요즘 로컬 우선 MVP 설계

작성일: 2026-07-27

## 1. 제품 정의

`그때요즘`은 5060 사용자가 하루 60~90초 동안 부담 없이 세 문제를 풀고, 잘 맞히는 즐거움과 가벼운 세대 공감을 얻는 앱인토스 비게임 미니앱이다.

하루 기본 문제는 다음 세 범주에서 한 문제씩 제공한다.

- 그때: 추억, 옛날 생활, 문화와 시대 상식
- 요즘: 스마트폰, 디지털 용어, 최신 생활 방식
- 생활: 생활안전, 말·속담·맞춤법, 알아두면 좋은 실용 상식

앱은 사용자를 시험하거나 나이 듦을 강조하지 않는다. 브랜드 표현은 `시니어 훈련`이 아니라 `우리 세대가 잘 아는 것과 새롭게 알아가는 것을 함께 즐기는 퀴즈`에 맞춘다.

## 2. MVP 목표와 제외 범위

### 목표

- 앱 진입 후 1탭 안에 첫 문제를 시작할 수 있다.
- 기본 세 문제를 중단 없이 완료할 수 있다.
- 정답 여부, 짧은 해설, 출처를 즉시 확인할 수 있다.
- 완료 결과와 연속 참여일을 확인할 수 있다.
- 여섯 주제 중 하나를 골라 첫 보너스는 무료로, 이후에는 무료 보너스권 또는 선택형 보상 광고로 세 문제를 더 풀 수 있다.
- 페이지를 닫았다 다시 열어도 오늘의 진행 상태가 복구된다.

### 제외 범위

- 서버, 관리자 페이지, 원격 콘텐츠 배포
- 토스 로그인, 인앱 결제, 유료 구독
- 실시간 친구 대결과 공유 리워드
- 현금성 또는 환가 가능한 포인트
- 랭킹, 커뮤니티, 댓글, 복잡한 상점

## 3. 핵심 사용자 흐름

1. 사용자가 앱에 진입한다.
2. 홈에서 오늘의 날짜, 세 문제 구성, 연속 참여일을 확인한다.
3. `오늘의 3문제 시작`을 누른다.
4. 문제와 세 개의 답안을 확인하고 하나를 선택한다.
5. 정답 여부, 아이콘, 짧은 해설과 출처를 확인한다.
6. `다음 문제`를 눌러 같은 흐름을 반복한다.
7. 세 문제 완료 후 점수, 범주별 결과, 연속 참여일을 확인한다.
8. 사용자는 종료하거나 보너스 주제 여섯 개 중 하나를 선택한다.
9. 첫 보너스는 광고 없이 열리고, 이후에는 무료 보너스권을 먼저 사용한다.
10. 무료 보너스권이 없을 때만 사용자가 보상 광고를 선택할 수 있으며, 완료되면 보너스 세 문제를 푼다.
11. 3일·7일 연속 참여에 도달할 때마다 다음 보너스에 쓸 무료권 한 장을 받는다.

기본 문제, 해설, 결과는 광고 없이 항상 이용할 수 있어야 하며 핵심 흐름에 강제 광고·전면 광고·배너 광고를 넣지 않는다.

## 4. 화면과 컴포넌트

### 홈

- 브랜드명 `그때요즘`
- 오늘 날짜를 보여 주는 하루 달력 카드
- `그때 · 요즘 · 생활` 문제 구성 안내
- 연속 참여일
- 단일 주요 버튼 `오늘의 3문제 시작`
- 이미 완료한 날에는 `오늘 결과 보기`

첫 진입에서 알림 동의, 광고, 페이월 또는 설명 모달을 띄우지 않는다.

### 퀴즈

- 진행 상태 `1/3`
- 범주 라벨
- 문제 문장
- 세 개의 답안 버튼
- 선택 후 정답/오답 상태, 아이콘과 문구
- 한두 문장의 해설
- 출처명
- `다음 문제` 또는 `결과 보기`

### 결과

- 오늘 점수
- 문제별 정답 여부
- 가장 잘 맞힌 범주 또는 격려 문구
- 연속 참여일
- 무료 보너스권 잔액과 새 무료권 지급 안내
- `좋아하는 주제로 3문제 더 풀기`
- `처음으로`

### 보너스 주제 선택

- `추억·대중문화`, `한국 생활사`, `말·속담·맞춤법`, `디지털 생활`, `생활안전`, `자연·일반상식` 여섯 주제를 큰 선택 카드로 보여 준다.
- 현재 해제 수단을 `첫 이용 무료`, `무료 보너스권 1장 사용`, `광고 보고 시작` 중 하나로 명확히 설명한다.
- 선택한 주제의 미풀이 문제를 우선하고, 세 문제가 부족하면 다른 미풀이 주제를 포함했다는 안내를 보여 준다.

### 보상 광고

- 실제 광고 화면을 흉내 내지 않는다.
- 개발 환경에서는 안내 화면과 짧은 진행 상태만 제공하고, 샌드박스·프로덕션에서는 공식 어댑터를 사용한다.
- 첫 무료 보너스와 무료 보너스권을 모두 소진한 경우에만 제안한다.
- 광고 공급자 인터페이스 뒤에 숨겨 모의·공식 구현을 교체할 수 있게 한다.
- 실패 시 `광고를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`와 재시도/닫기를 제공한다.

## 5. 시각 디자인

### 방향

토스 안에서 낯설지 않은 구조를 유지하면서, `하루치 달력을 한 장씩 넘기는 경험`을 브랜드 특징으로 사용한다. 장식보다 날짜, 범주, 진행 순서가 시각 구조를 결정한다.

### 색상

- 잉크 남색 `#24364B`: 본문과 핵심 정보
- 토스 블루 `#3182F6`: 주요 동작과 포커스
- 해돋이 노랑 `#FFD56A`: 오늘 날짜와 긍정적 강조
- 안개 회색 `#F2F5F8`: 배경과 구획
- 흰색 `#FFFFFF`: 문제 카드

정답과 오답은 색상만으로 전달하지 않고 아이콘과 `정답이에요`, `아쉬워요` 문구를 함께 사용한다.

### 타이포그래피와 크기

- 한국어 가독성과 로딩 안정성을 위해 시스템 산세리프 계열을 사용한다.
- 본문 기본 18px, 문제 24~28px, 보조 정보 최소 15px
- 답안 버튼 높이 최소 56px
- 좌측 정렬을 기본으로 하고 긴 문장의 중앙 정렬을 피한다.

### 움직임

문제 전환에서 달력 한 장이 살짝 올라가는 듯한 짧은 `opacity + transform` 전환만 사용한다. `prefers-reduced-motion`에서는 전환을 제거한다.

## 6. 기술 구조

### 기반

- React
- TypeScript
- Vite 기반 앱인토스 WebView 프로젝트
- 클라이언트 사이드 렌더링

실제 앱인토스 SDK 의존성은 프로젝트 생성 시점의 공식 문서와 패키지 버전을 확인해 결정한다.

### 모듈 경계

- `domain/quiz`: 문제 모델, 채점, 진행 상태 전환
- `domain/bonus`: 주제 선택, 무료권 지급·차감, 보너스 해제 우선순위
- `data/questions`: 로컬 기본/보너스 문제
- `services/storage`: 진행 상태 저장 인터페이스와 브라우저 구현
- `services/reward-ad`: 보상 광고 인터페이스와 모의 구현
- `features/home`: 홈 화면
- `features/quiz`: 기본/보너스 퀴즈 화면
- `features/result`: 결과 화면
- `features/bonus-topic`: 보너스 주제와 해제 수단 선택 화면
- `ui`: 재사용 가능한 버튼, 카드, 진행 표시

퀴즈 도메인은 React, 브라우저 저장소, 광고 SDK를 직접 참조하지 않는다.

## 7. 데이터 모델

문제는 다음 정보를 가진다.

- 고유 ID
- 핵심 렌즈: `then`, `now`, `life`
- 보너스 주제: `nostalgia`, `korean-life`, `language`, `digital`, `safety`, `nature-general`
- 질문
- 세 개의 답안
- 정답 인덱스
- 해설
- 출처명
- 출처 URL 또는 내부 출처 식별자
- 난이도: `easy`, `normal`
- 검수일
- 보너스 문제 여부

초기 샘플은 기본 세 문제와 보너스 세 문제를 제공한다. 구조 검증용이므로 의료, 투자, 법률 조언이나 저작권 이미지·가사·방송 캡처를 포함하지 않는다.

## 8. 상태와 저장

진행 상태는 날짜별로 저장한다.

- 오늘 문제 순서
- 현재 문제 위치
- 선택한 답
- 기본 문제 완료 여부
- 보너스 잠금 해제 및 완료 여부
- 첫 무료 보너스 사용 여부
- 무료 보너스권 잔액과 `streakStartDate + milestone` 지급 키
- 보너스권·광고 해제 시도 키와 선택한 주제
- 연속 참여일

날짜가 바뀌면 새 일일 세션을 생성한다. 저장 데이터가 손상됐거나 이전 버전과 호환되지 않으면 오늘 세션만 안전하게 초기화하고 앱 전체를 막지 않는다.

## 9. 오류와 빈 상태

- 로컬 문제를 읽지 못하면 복구 안내와 다시 시작 버튼을 제공한다.
- 저장 실패 시 현재 세션은 메모리에서 계속 진행하고 결과 화면에서 저장 실패를 조용히 안내한다.
- 보너스 주제의 미풀이 문제가 부족하면 다른 주제의 미풀이 문제로 채우고 이를 시작 전에 알린다.
- 광고 실패는 기본 퀴즈 결과와 무료권 잔액에 영향을 주지 않는다.
- 무료권 차감과 광고 보상은 같은 시도가 중복 처리돼도 한 번만 반영한다.
- 이미 답한 문제에서는 답안을 변경할 수 없다.
- 빠른 연속 탭으로 두 문제를 건너뛰지 않도록 전환 중 버튼을 잠근다.

## 10. 테스트와 검수

### 자동 테스트

- 정답/오답 채점
- 답변 후 다음 문제로 전환
- 기본 세 문제 완료
- 첫 보너스 무료 해제는 최초 한 번만 처리
- 3일·7일 연속 참여 무료권 지급과 멱등 차감
- 선택 주제 우선 보너스 구성과 미풀이 부족 폴백
- 무료 해제 수단이 없을 때의 모의 광고 성공/취소/실패
- 저장 및 복구
- 날짜 변경 시 새 세션 생성
- 손상된 저장 데이터 복구

### 수동 검수

- 360px 너비 모바일 화면에서 잘림 없음
- 200% 글자 확대에서도 핵심 동작 가능
- 키보드만으로 답안 선택과 다음 이동 가능
- 포커스 표시가 명확함
- 색상 없이도 정답/오답 구분 가능
- 감소된 모션 설정 존중
- 새로고침 후 진행 상태 복구

## 11. MVP 완료 기준

- 홈, 기본 퀴즈, 결과, 보너스 주제 선택, 첫 무료·무료권·광고 해제, 보너스 퀴즈 흐름이 모두 동작한다.
- 기본 세 문제·해설·결과와 첫 보너스 세 문제는 광고 없이 완료할 수 있다.
- 3일·7일 연속 참여 무료권은 각 연속 참여 구간에서 한 번씩만 지급되고 한 번만 차감된다.
- 모의 광고 구현을 실제 광고 어댑터로 교체할 수 있다.
- 자동 테스트가 통과한다.
- 프로덕션 빌드가 성공한다.
- 모바일 화면과 접근성 핵심 항목을 직접 검수한다.

## 12. 후속 단계

MVP 사용성 검증 이후에만 다음을 검토한다.

1. 앱인토스 익명 사용자 식별키 연동
2. 원격 문제 API와 콘텐츠 검수 도구
3. 친구에게 같은 문제 보내기
4. 광고 제거 비소모성 인앱 결제
5. 스마트 발송과 프로모션

5. 서로 다른 날짜에 두 번 완료한 뒤 제공하는 알림 선택권
6. 핵심 문제는 모두 동일하게 유지하고 여섯 주제 중 사용자가 고른 주제를 우선하는 보너스 구성
7. 완료율 65%, D1 30%, D7 12%, 광고 선택률 15%, 공유 시도율 5%를 모두 충족하기 전 유료 프로모션 금지

상세한 구조, 오류·복구 정책, 테스트, 출시 게이트와 구현 작업은 `2026-07-27-geuttae-yojeum-ceo-review.md`를 최종 기준으로 삼는다. 비실시간 날짜 공유와 실제 보상 광고 어댑터는 현재 MVP 범위이며, 실시간 대전과 공유 리워드는 계속 제외한다.
